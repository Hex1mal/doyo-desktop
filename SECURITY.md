# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 1.0.x | Yes |

## Reporting A Vulnerability

Please report vulnerabilities privately before opening a public issue. If the GitHub repository is available, use GitHub private vulnerability reporting. Otherwise, contact the maintainer through the repository owner's preferred private channel.

## Data Handling

Doyo stores data locally in SQLite. Do not attach databases, backups, logs, or screenshots to public issues unless you have reviewed them for private content.
