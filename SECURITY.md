# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |

## Reporting A Vulnerability

Please report vulnerabilities privately before opening a public issue by using GitHub private vulnerability reporting on `Hex1mal/doyo-desktop`.

## Data Handling

Doyo stores data locally in SQLite. Do not attach databases, backups, logs, or screenshots to public issues unless you have reviewed them for private content.
